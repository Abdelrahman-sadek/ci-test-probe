# Staff guide: keeping the assistant up to date

## Add or update a page (no coding)
1. Open `https://<assistant>/admin`. With single sign-on you are recognised automatically; otherwise paste the admin key.
2. Choose a file: Markdown, text, HTML, PDF or an image (scans are read with OCR).
3. Give it a **title** and the **official URL** (it must be on an approved domain such as `aucegypt.edu`).
4. Choose **who can see it**: everyone, students, faculty or library staff.
5. Press **Upload and index**. The status line reports how many passages were indexed.

## Review changed pages
When a re-crawled page changes, it is held until a librarian approves it, so an edited or tampered page can't reach students unchecked. The **Changed sources waiting for review** list shows each one; press **Approve** after checking the official page.

## Good pages for the assistant
- One topic per page, with clear headings (`## Loan periods`, `## Renewals`).
- Write facts as full sentences: "Alumni can borrow up to 5 books for 14 days."
- Put the date in the page (`updated:`) and refresh pages every semester.
- Never upload personal data (names with IDs, emails, phone lists).

# دليل الموظفين: تحديث المساعد

## إضافة صفحة أو تحديثها بدون برمجة
١. افتح صفحة `/admin`. عند استخدام الدخول الموحد يتم التعرف عليك تلقائيًا، وإلا فأدخل مفتاح المسؤول.
٢. اختر ملفًا: Markdown أو نص أو HTML أو PDF أو صورة (تُقرأ الصور الممسوحة ضوئيًا بتقنية التعرف الضوئي على الحروف).
٣. اكتب **العنوان** و**الرابط الرسمي** (يجب أن يكون على نطاق معتمد مثل `aucegypt.edu`).
٤. اختر **من يمكنه رؤيتها**: الجميع أو الطلاب أو أعضاء هيئة التدريس أو موظفو المكتبة.
٥. اضغط **Upload and index**، وسيظهر عدد الفقرات التي تمت فهرستها.

## مراجعة الصفحات المتغيرة
عندما تتغير صفحة أُعيد جلبها، تُحجز حتى يوافق عليها أمين مكتبة، حتى لا تصل صفحة معدّلة أو مُتلاعب بها إلى الطلاب دون مراجعة. اضغط **Approve** بعد التحقق من الصفحة الرسمية.

## نصائح لصفحات جيدة
- موضوع واحد لكل صفحة، مع عناوين واضحة.
- اكتب الحقائق في جمل كاملة: "يمكن للخريجين استعارة حتى 5 كتب لمدة 14 يومًا."
- لا ترفع أي بيانات شخصية.
