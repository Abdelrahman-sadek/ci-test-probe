# مجموعة الوكلاء ومساعد مكتبة الجامعة الأمريكية بالقاهرة

مجموعة من ٢٠ وكيل ذكاء اصطناعي خفيف، مع تطبيق جاهز يجمع **التعرف الضوئي على الحروف ← البحث الهجين ← محادثة آمنة** لمكتبات الجامعة الأمريكية بالقاهرة، بالعربية والإنجليزية والفرانكو.

> مشروع مستقل وغير تابع للجامعة الأمريكية بالقاهرة.

## التشغيل بأمر واحد
```bash
cp .env.example .env
docker compose up -d
```
ثم افتح الموقع: صفحة المحادثة على `/` وصفحة الموظفين على `/admin`.

## ماذا يقدّم
- **إجابات موثقة فقط:** كل إجابة تذكر مصدرها الرسمي، وإن لم توجد معلومة يُحال السائل إلى أمين المكتبة.
- **العربية أولًا:** واجهة عربية كاملة من اليمين إلى اليسار، وفهم للعامية المصرية والفرانكو، وإدخال صوتي.
- **سهولة الوصول:** متوافق مع معايير WCAG 2.2 AA (صفر مخالفات في اختبار axe)، ويعمل مع قارئات الشاشة ولوحة المفاتيح.
- **قنوات متعددة:** موقع المكتبة (أداة مدمجة)، وواتساب، وأي تطبيق يدعم MCP.
- **حماية البيانات:** حذف البيانات الشخصية قبل إرسال السؤال للنموذج، وسجلات مشفرة بأسماء مستعارة تُحذف بعد ٣٠ يومًا، وتسجيل دخول موحد مع صلاحيات حسب المجموعة.
- **أمان:** صدّ ٣٠ من ٣٠ هجومًا في اختبار الاختراق (حقن الأوامر بالعربية والإنجليزية والفرانكو، وداخل المستندات).
- **قابلية التوسع:** فهرس SQLite يبحث في ١٠٠ ألف فقرة خلال أقل من ربع ثانية، وذاكرة مؤقتة للإجابات، ومؤشرات أداء وتكلفة.

## للموظفين
راجع [دليل الموظفين](docs/STAFF-GUIDE.md): إضافة الصفحات بدون برمجة، ومراجعة الصفحات المتغيرة قبل نشرها.

## قبل الإطلاق
- التحقق من المعلومات في `knowledge/auc-library/` (كل ما عليه علامة `[VERIFY]`).
- تحديد نظام الدخول الموحد للجامعة والمجموعات في `config/access.json`.
- مراجعة [سياسة البيانات](docs/DATA-POLICY.md) مع الإدارة القانونية (قانون حماية البيانات الشخصية رقم ١٥١ لسنة ٢٠٢٠).
